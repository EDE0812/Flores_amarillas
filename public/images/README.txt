=====================================================
🌻 CARPETA PARA TUS FOTOS DE PAREJA 📸
=====================================================

¡Hola! Aquí puedes colocar las fotos que desees mostrar en la página web.

Recomendaciones:
1. Copia aquí tus fotos con nombres como:
   - foto1.jpg
   - foto2.jpg
   - foto3.jpg
   - foto4.jpg
   - foto5.jpg
   - foto6.jpg

2. Si las guardas con otros nombres o formatos (.png, .webp), puedes actualizar las rutas en el archivo `src/components/PhotoGallery.jsx`.

¡La página web las cargará automáticamente!
